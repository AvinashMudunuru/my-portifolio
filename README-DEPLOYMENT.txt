DEPLOY
1. Download and extract this ZIP on your computer.
2. Back up your current GitHub repository first.
3. Replace the repository's website files with the CONTENTS of this extracted folder.
   Do not upload the ZIP file itself and do not nest the folder inside the repository.
4. Keep the repository's main branch.
5. In GitHub: Settings > Pages, use GitHub Actions as the build/deployment source.
6. Confirm the custom domain is avinashmudunuru.in and HTTPS is enabled.
7. Commit and push. Wait for the GitHub Actions deployment to complete.
